# Added

- Import Card for AE2 Pattern Providers, which collects the results of every pattern the Provider sends out back into the network from the side it sent them to, including results still in flight when a job is cancelled
- Import Card support in the pattern providers from Advanced AE, ExtendedAE, Expanded AE, MEGA Cells, Applied Create and the AE2 Draconic Fusion Autocrafter, collecting fusion results straight out of the Fusion Crafting Core
- Not Enough Patterns compatibility: with both installed this mod stands aside for Not Enough Patterns' own Import Card, and installed cards and pending imports carry over when either mod is added or removed
